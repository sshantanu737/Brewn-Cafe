# Brewn Cafe

A warm, minimal, and elegant website for **brewn** — a local craft coffee & pastries cafe. The design is inspired by the cafe's logo, using its rich chocolate tones and warm cream palette to create a cozy digital experience that matches the ambience of the physical space.

## Sections

- **Hero** — Bold brand moment with the cafe name and tagline, set against the logo's signature chocolate background
- **About** — The story behind brewn, with three core values (small-batch roast, house baked, made with care)
- **Menu** — Featured coffee drinks and fresh pastries with prices, displayed on a dark background for visual contrast
- **Visit Us** — Location, hours, and contact details with a call-to-action to book a table

## Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom styles with CSS variables, grid, flexbox, responsive media queries, and smooth scroll-reveal animations
- **Vanilla JavaScript** — Lightweight interactivity (mobile nav toggle, scroll-triggered reveals, sticky nav with frosted-glass effect)
- **Google Fonts** — DM Serif Display for headings, DM Sans for body text

## Features

- Fully responsive design (mobile, tablet, desktop)
- Smooth scroll-reveal animations on each section
- Sticky navigation with frosted-glass effect on scroll
- Mobile hamburger menu with animated toggle
- Single self-contained HTML file — no build tools or dependencies needed
- Accessible: proper ARIA labels, keyboard navigation support, and reduced-motion respected

## How to Use

1. Open `index.html` (or `brewwn.html`) in any modern browser
2. Or deploy to any static hosting service (Netlify, GitHub Pages, Vercel, etc.)
